# hokkaido-winter-route

北海道冬季两条路线的出行风险判定：判定规则、高速封路日志，以及每天两次判定的记录。

- 路线甲：札幌—旭山動物園—美瑛—白金（青い池）一日游，回程走道道353、国道237、道道135、国道452 到三笠IC 上道央道。
- 路线乙：小樽⇔札幌⇔新千歳空港（札樽道、道央道）。
- 公开网站：https://hokkaido-winter-route.netlify.app （目前仍按 v3 规则计算，以每天的报告为准）。

## 目录

- `rules/v4.md`：判定规则，晚间日报（20:20，看未来 7 天）和晨间复查（06:20，看当天和第二天）共用的唯一版本。
- `data/closures.csv`：高速封路日志，从 2025–26 年冬季开始，每条写开始、解除、区间、原因、出处和核对程度，用来回测规则。
- `state/`：每次判定结束后写入的记录（定时任务接入仓库后开始写）。
  - `state/latest.json`：最近一次判定的各天、各段、各时段等级和关键数值，下一次运行读它，才能写"比上次升级／降级"。
  - `state/log/年/月/日-evening.md`、`日-morning.md`：每次报告全文。

## 这里不放什么

仓库是公开的，任何人都能看。行程日期、住址、联系方式这类个人信息一律不放进来。
