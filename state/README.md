1. `latest.json`：最近一次运行的结论，每次覆盖。格式：

   ```json
   {"run": "evening", "run_time": "2026-11-25T20:24+09:00", "rules": "v4",
    "days": [
     {"date": "2026-11-26",
      "route_a": {"level": "🟠", "type": "大雪", "rule": "O2", "where": "去程高速 岩見沢—滝川 09–11 时"},
      "route_b": {"level": "🟢", "type": "", "rule": "", "where": ""}}
    ],
    "closures": "未查到封闭消息",
    "missing": ["B4 集合预报"]}
   ```

   - `run`：evening（晚间日报，days 是明天起的七天）或 morning（晨间复查，days 是今天和明天）。
   - `route_a` 是一日游（札幌—旭山—美瑛—白金），`route_b` 是机场线（小樽⇔札幌⇔新千歳空港）。
   - `level` 用 ⬛🔴🟠🟢⬜ 五个符号；`type` 是风险类型（吹雪、大雪、结冰、其他、只有风）；`rule` 是触发的规则编号，对应 `rules/v4.md`；`where` 写哪一段、哪几个小时。
   - `closures` 是运行时查到的封路、停运消息；`missing` 是这次没取到的数据。

2. `log/年/月/日-evening.md`、`日-morning.md`：那次报告的全文。

启用后，下一次运行只读 `latest.json` 和最新一份报告，用来写"和上一次比哪里变了"；判级仍只看当次取到的数据。

仓库是公开的，这里不存任何个人信息。
